LESSON 01

What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on webpages.

HTML tells the browser what different pieces of content are. For example, a heading is different from a paragraph, an image or a link.

Think of a website like a house:
  • HTML = structure
  • CSS = appearance
  • JavaScript = behavior
LESSON 02

HTML Document Structure

Every normal HTML document has a basic structure. 

<!DOCTYPE html>
<html lang="en">

<head>
  <title>My Website</title>
</head>

<body>

  <h1>Hello World</h1>

</body>

</html>
Important:

The <head> contains information about the document, while the <body> contains the content users see.

LESSON 03

Tags, Elements & Attributes

HTML is built using elements. Most elements have an opening tag and closing tag. 

<p>Hello World</p>

Here, <p> is the opening tag and </p> is the closing tag.

Attributes provide additional information. 

<a href="https://example.com">
  Visit Website
</a>

Here, href is an attribute.

LESSON 04

Headings

HTML has six heading levels, from <h1> to <h6>. 

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection</h3>
<h4>Smaller Heading</h4>
<h5>Smaller Heading</h5>
<h6>Smallest Heading</h6>
Best practice:

Use headings to create a logical content hierarchy rather than simply choosing a heading because it looks bigger.

LESSON 05

Paragraphs & Text

<p>
  HTML is used to structure webpages.
</p>

You can also emphasize text using semantic elements. 

<strong>Important text</strong>

<em>Emphasized text</em>

<mark>Highlighted text</mark>
LESSON 06

Links

The anchor element creates hyperlinks. 

<a href="https://example.com">
  Visit Example
</a>

You can also link to another page in your own website. 

<a href="about.html">
  About Us
</a>

To open a link in a new tab: 

<a
  href="https://example.com"
  target="_blank"
  rel="noopener"
>
  Open Website
</a>
LESSON 07

Images

Images are added using the <img> element. 

<img
  src="photo.jpg"
  alt="A person standing outside"
>
⚠️ Don't forget alt text.

The alt attribute provides a text alternative for an image.

LESSON 08

Lists

Unordered list

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Ordered list

<ol>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Learn JavaScript</li>
</ol>
LESSON 09

Tables

Tables are used for tabular data. 

<table>

  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>

  <tr>
    <td>John</td>
    <td>25</td>
  </tr>

</table>

<tr> creates a row, <th> creates a header cell and <td> creates a data cell.

LESSON 10

Forms

Forms allow users to submit information. 

<form>

  <label>Name</label>

  <input
    type="text"
    placeholder="Enter your name"
  >

  <button type="submit">
    Submit
  </button>

</form>
LESSON 11

Input Types

HTML provides different input types for different kinds of data. 

<input type="text">

<input type="email">

<input type="password">

<input type="number">

<input type="date">

<input type="checkbox">

<input type="radio">

<input type="file">

<input type="submit">
LESSON 12

Labels & Form Accessibility

Labels tell users what an input field is for. They also help assistive technologies. 

<label for="email">
  Email Address
</label>

<input
  id="email"
  type="email"
>
Remember:

The label's for value should match the input's id.

Audio & Video

Audio

<audio controls>
  <source
    src="music.mp3"
    type="audio/mpeg"
  >
</audio>

Video

<video controls width="600">
  <source
    src="video.mp4"
    type="video/mp4"
  >

LESSON 14

Div & Span

<div> is a generic block container. 

<div>
  <h2>My Section</h2>
  <p>Some content</p>
</div>

<span> is commonly used for small pieces of inline content. 

<p>
  Learn
  <span>HTML</span>
  today.
</p>
LESSON 15

Classes & IDs

Classes and IDs allow elements to be identified and styled. 

<p class="intro">
  Welcome!
</p>

<section id="about">
  About us
</section>

A class can be reused on multiple elements. An ID should identify a unique element within the document.

LESSON 16

Semantic HTML

Semantic elements communicate the purpose of different parts of a webpage. 

<header>
  Website Header
</header>

<nav>
  Navigation
</nav>

<main>

  <section>
    Main Section
  </section>

  <article>
    Article
  </article>

</main>

<footer>
  Website Footer
</footer>

Common semantic elements include header, nav, main, section, article and footer.

LESSON 17

Comments

Comments are notes in your code that the browser does not display as webpage content. 

<!--
  This is a comment.
-->

Comments are useful for explaining sections of your code.

LESSON 18

HTML Entities

Some characters have special meanings in HTML and need to be represented using entities. 

&lt;   <
&gt;   >
&amp;  &
&copy; ©
&nbsp; space
LESSON 19

Meta Information

Metadata provides information about your webpage to browsers and other systems. 

<meta charset="UTF-8">

<meta
  name="viewport"
  content="width=device-width,
  initial-scale=1.0"
>

<meta
  name="description"
  content="Learn HTML from zero."
>
LESSON 20

HTML & Accessibility

Accessible HTML helps people with different abilities use your website.

  • Use meaningful headings.
  • Add useful alt text to images.
  • Use labels with form controls.
  • Use semantic HTML where appropriate.
  • Make links descriptive.
Example:

Prefer "Read our pricing guide" over a vague link such as "Click here."

LESSON 21

HTML & SEO

Good HTML structure can help search engines understand your content. 

<title>
  Learn HTML | HTML Mastery
</title>

<meta
  name="description"
  content="A complete HTML course
  for beginners."
>

Clear headings, meaningful page titles, descriptive links and useful content are important parts of a well-structured webpage.

LESSON 22

HTML Validation

Browsers can often recover from mistakes, but valid, well-structured HTML is easier to maintain and understand.

Common mistakes:
  • Forgetting closing tags.
  • Incorrect nesting.
  • Missing quotation marks.
  • Missing alt text.
  • Using inappropriate elements.

LESSON 24

Build a Complete Webpage

Now combine what you've learned. 

<!DOCTYPE html>

<head>

  <meta charset="UTF-8">

  <title>
    My Website
  </title>

</head>

<body>

  <header>

    <h1>
      My Website
    </h1>

    <nav>

      <a href="#">
        Home
      </a>

      <a href="#">
        About
      </a>

    </nav>

  </header>


  <main>

    <section>

      <h2>
        Welcome
      </h2>

      <p>
        This is my first website.
      </p>

      <img
        src="photo.jpg"
        alt="My photo"
      >

    </section>

  </main>


  <footer>

    <p>
      © 2026 My Website
    </p>

  </footer>

</body>

</html>
